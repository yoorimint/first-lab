# 운영자 지시 기록 (최신이 위)

다른 세션이 이어받을 때 읽는다. 운영자가 한 말 중 지금도 유효한 것만, 짧게.

## 말하기·일하는 방식
- 항상 **한글로만** 말한다 (중간 안내 포함). 짧게, 바꾼 것과 결과만.
- 나는 시스템 설계자: 오류는 말하기 전에 찾아 고치고, **고칠 때마다 다시 안 생기게** 코드·테스트로 막는다. 묻지 말고 처리 후 보고.
- 운영자에게 수작업을 시키지 않는다 (비밀값만 서버 `set-secrets.sh`). 비밀번호·키를 채팅으로 받지 않는다.
- 글쓰기 규칙(지시서)은 늘리지 않는다 — 많으면 할루시네이션이 는다. 코드로 막는다.
- 중요한 제품 결정(디자인 방향 등)은 운영자에게 묻는다.

## 감시·검수 (11/4)
- 35분마다 감시, **새로 만든 초안은 전부 바로 외부 검수** → 결과는 내가 한 번 더 훑고 수정 + 재발 방지. 그만하라고 할 때까지.
- 검수자는 Opus 로 지정.
- 초안 단계에서 완벽해야 함: 공개는 시간이 되면 내보내기만 한다. 이미 끝난 초안을 공개 직전에 다시 검수하는 방식은 원하지 않음.

## 결정된 것
- 글 분량 2,000자 (11/4 운영자가 설정에서 변경 — 곁가지 문장을 줄여 오류를 줄임). 검수는 지금 방식 유지(별도 검수 단계 만들지 않음), 외부 검수로 1~2일 측정.
- 글: Claude 월정액 예약 작업으로 작성 (API 비용 추가 없음, Gemini 도 안 씀). 네이버 검색 API 제안 금지.
- 연속 작성(시작/정지 버튼)으로 초안을 쌓고, 예약 공개 시각(± 랜덤)에 오래된 초안부터 공개.
- 사진: 글마다 AI 대표 사진 1장 (홈 목록·공유 미리보기). 본문 안에는 사진 없음, 글 화면 맨 위에 대표 사진 1장 (11/4 운영자 결정, 제목 카드는 숨김). 글자 깨진 사진은 자동 사진 검사로 교체.
- 홈: 큰 대표 글 1개 + 사진 목록. 대표 글 = 고정 글 → 서치콘솔 클릭 1위 → 최신.
- 상단 메뉴는 '계산기' 하나. 소개·문의·개인정보는 바닥글.
- 표: 휴대폰 폭에 안 들어가면 카드 모양.
- 계산기: 키워드에 '계산기'가 있으면 만든다. 상위 글 분석은 질문·목차만 참고(문장·사실 복사 금지).
- 애드센스 승인 뒤: 광고 지연 로딩(속도), 쿠팡 하단 고정 배너(대가성 문구, 애드센스 앵커 광고와 겹치지 않게).
- 댓글 끔.
- 파비콘(검색 결과·탭 아이콘): 파란 둥근 사각형에 흰 F (11/5). 바꾸려면 server/make-icons.py 상수만 고쳐 다시 실행.
