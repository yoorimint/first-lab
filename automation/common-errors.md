# 자주 틀린 유형 (자동 생성: automation/common_errors.py — 직접 고치지 않음)

외부 검수에서 고친 763곳을 유형별로 센 것. 많은 순. 검수할 때 이 유형부터 확인한다.

## 조건·예외·범위 누락 (349곳)
- 왜 틀렸나: 안내 페이지는 원칙만 적고 예외를 빼는 경우가 많은데, 법령 조문 전체(단서·다음 항)를 읽지 않음 (#416·#491·#512). 기관 안내 페이지 맨 위 요약 상자만 옮김 (#578 버팀목: 요약 '무주택 세대주' → 상세는 '세대원 전원 무주택', 면적·보증금 요건). 근로기준법 연장수당·연차(4명 이하 미적용)를 요약에 조건 없이 씀 (#613·#630) → 관문이 막음. 조문이 나열한 경우(각 호) 중 일부만 씀 (11/5 #651 출근 간주에서 유산·사산휴가, #687 대체공휴일 '평일에 다른 공휴일과 겹침') → 근거 대조가 각 호를 보여 줌. 다른 조문의 특례(#640 제53조 ← 제53조의2)·제목 범위 조건(#651·#655) → 관문이 막음 (bot/condition_gate.py). 첫 문단은 단정('대상이 아니에요')인데 본문 아래에 예외('…때 대상이면 지원')가 있음 (#748, 글쓰기 작업 검수도 놓침) → 관문이 막음(condition_gate.lead_vs_body). 요약은 '받아요'인데 본문에 '못 받는 경우' 목록(#762) → 관문(excerpt_vs_exclusions). 개정된 상한액을 적용 시점 없이 씀 — 부칙 경과조치로 2025년 퇴사자는 종전 66,000원(#762) → 관문(transition_rules). 요약·첫 문단은 '신용평점 하위 10%'만, 본문은 '기초생활수급자 등이라면 하위 20%', 제목은 '피해자'만(본문은 '불법사금융 피해자') (#771) → 관문(lead_thresholds·title_qualifier). 첫 문단 '둘 다 3개월 이상 일해야' ↔ 본문 '일용근로자는 90일 중 45일 이상'(#775) → 관문(lead_minimums). 5등급제·9등급제를 나눠 설명하면서 갈래 없이 '융합 선택 과목은 성취도만 적고'(#784, 같은 꼴 2번) → 관문(variant_only). 요약은 '11월 27일부터 10%에서 40%'인데 본문은 '시행 이후 신고한 경우부터'(#817, 같은 꼴 3번째: #762·#808) → 관문(excerpt_apply_date).
- 쓸 때: '~만·모두·항상·불가·없어요' 같은 단정은 예외·조건(제외 대상, 둘 중 하나·합산 여부, ~일 때만)을 원문에서 확인. 기관 상품 안내 페이지는 맨 위 요약 줄 말고 아래 상세 '대상·대상주택' 요건을 옮긴다. 조문이 '다음 각 호'로 경우를 나열하면 근거 대조의 [경우 나열]을 보고 모두 쓰거나 '등'으로.
  - 예 (글 1670): 근로기준법 시행령 제3조(법제처 원문): '일용근로자의 평균임금은 고용노동부장관이 사업이나 직업에 따라 정하는 금액으로 한다' — 고시·행정해석 확인 못 해 단정 완화
  - 예 (글 1673): 소득세법 제59조의3④(법제처 원문): '직전 과세기간과 해당 과세기간에 걸쳐 납입한 경우에는 300만원에서 직전 과세기간에 적용된 금액을 차감'

## 공식 근거로 확인 안 된 내용을 단정 (192곳)
- 왜 틀렸나: 읽지 못한 화면(심평원·홈택스처럼 스크립트로 채우는 페이지)이나 열지 않은 페이지를 근거로 적고 '맞음'으로 기록함 (#465·#484).
- 쓸 때: 공식 페이지를 직접 열어 그 문장을 본 것만 단정. 메뉴 경로·ARS 번호·화면 입력 항목·운영시간처럼 화면에서만 보이는 세부는 열어서 못 봤으면 '○○에서 확인'으로.
  - 예 (글 1645): moel.go.kr/policy/policyinfo/lobar/list4.do 가 '기술적인 문제로 서비스에 접속이 되지 않았습니다' 화면(직접 확인) — 임금체불 안내인지 확인 못 함
  - 예 (글 1643): 카드사 공식식은 사용일수/365 — 첫 회차 일수 차이로 '몇백 원'보다 클 수 있음(120만·15%면 하루 약 493원), 범위 공식 근거 없음

## 사실 자체가 틀림 (기관·명칭·서류·기간 등) (96곳)
- 왜 틀렸나: 안내 페이지·기사의 쉬운 말(예: '지자체에 내요')을 법령 원문(시·도지사에게 제출)과 대조하지 않음 (#482·#493).
- 쓸 때: 기관·명칭·제출처·서류·주체(누가 정하고 누가 승인하는지)는 그 기관·법령 원문 표현 그대로.
  - 예 (글 1630): 소득세법 제14조③8호가목: 기타소득금액 300만원 이하 원천징수 소득은 분리과세(합산 선택 시 제외) — '끝난 세금이 아니에요·최종 세금은 한 해 전체 소득' 단정은 같은 문단과도 모순
  - 예 (글 1633): 근로기준법 제2조②(법제처 원문): '산출된 금액(평균임금)이 그 근로자의 통상임금보다 적으면 그 통상임금액을 평균임금으로' — 제목은 크기 관계가 거꾸로 읽힘

## 개정·최신 기준 미반영 (53곳)
- 왜 틀렸나: 안내 페이지·기사가 개정 전 내용인데 법령 현행본·부칙 시행일을 확인하지 않음 (#113·#512 2026.7.1 개정).
- 쓸 때: 올해 개정 여부를 법령 현행본(부칙의 시행일 포함)으로 확인. 보도자료·기사 값은 날짜를 밝히고 현행 원문으로 다시 확인.
  - 예 (글 1450): 복지로 안내 페이지 첨부는 '2023년 응급안전안심서비스 지역센터 명단'(등록 2023) — 지금 명단이 아닐 수 있음
  - 예 (글 1360): 경기도 산모·신생아 건강관리 150% 초과(추가형·라형) 지원 2026.10.1 종료 — 파주시보건소 공지 '추가형은 10.1.자 지원종료', 경인일보 2026.9.16

## 제목·요약이 본문·근거와 불일치 계산 값은 맞는데 안내 문장이 틀림 — 2001년생 입학 연기에 2008년 신설 신청 절차 안내(11/5 졸업년도 계산기) → 검사기가 사례마다 notes_include/notes_exclude 확인. (27곳)
- 왜 틀렸나: 본문을 고친 뒤 제목·요약을 같이 안 고침, 조건이 붙는 숫자를 제목에 하나만 씀 (#416·#493).
- 쓸 때: 제목·요약 숫자와 표현은 본문·검수된 주장과 같게.
  - 예 (글 771): 11/7 운영자 '계속 유효한 걸로 적어야': 되풀이 일정인데 제목·요약이 이번 회차 날짜에 묶여 회차가 지나면 글 전체가 지난 글이 됨
  - 예 (글 1423): 11/7 운영자 '계속 유효한 걸로 적어야': 되풀이 일정인데 제목·요약이 이번 회차 날짜에 묶여 회차가 지나면 글 전체가 지난 글이 됨

## 출처 없는 수치·표·민간 자료 (17곳)
- 왜 틀렸나: 블로그·민간 비교 사이트 값을 공식 자료처럼 씀 (초기 #34·#59).
- 쓸 때: 블로그·민간 자료의 금액·통계·표는 쓰지 않거나 '예시'라고 밝힌다.
  - 예 (글 896): '세발 제품은 30kg을 넘기 쉬워요'는 공식 근거 없음, 법 기준은 '30kg 미만'이라 30kg 이상이면 요건 밖 → 확인 안내로 (외부 검수 11/6)
  - 예 (글 549): '냉장실 안쪽 = 온도가 낮은 자리·달걀' 공식 근거 없음 (식약처: 안쪽도 자주 열면 온도 상승, 달걀은 문 쪽엔 금방 먹을 것만)

## 계산·계산기 오류 (17곳)
- 왜 틀렸나: 계산 결과를 손으로 다시 안 셈, 또는 계산기 입력·결과에 없는 기능을 글에서 약속함 (#493·#512). 자격 판정에서 법령 단서(부양자녀 나이 특례·장애인·기준기간 연장·직역연금 제외)를 빼 받을 수 있는 사람에게 '해당 안 됨' (11/5 혜택 찾기 검수). 보험료·세액을 1원 단위로 계산하고 건강보험 상·하한을 뺌 (11/5 월급 실수령액 계산기). 소수 곱셈 뒤 버림으로 1원 오차, 빈칸을 0으로 읽어 '없음' (11/5 주휴수당 계산기). 같은 1원 오차가 연장근로수당 계산기에서 또 남 → 모든 계산기 버림을 오차 보정 함수로, 검사기가 그냥 버림 금지.
- 쓸 때: 계산 예시·계산기는 법령 식대로 다시 계산하고 기준선(딱 그 값, 바로 아래·위)을 확인. 글에서 '계산기로 ○○를 알 수 있다'고 쓰는 것은 계산기 입력·결과에 실제로 있는 것만. 자격 판정 계산기는 '해당 안 됨'을 원문상 확실할 때만 내고, 입력으로 못 가리는 예외(단서·연장·특례)가 있으면 '조건 더 확인' — 예외마다 사례를 넣는다. 보험료·세금 계산은 끝수 규칙(국고금관리법 제47조: 10원 미만 버림)과 상한·하한 고시까지 넣는다. 버림은 Math.floor 대신 FirstLabCalc.util.floor/trunc (소수 오차로 1원 빠짐 — 검사기가 막음). 세금·보험료 계산기는 data 에 won10_keys(10원 단위여야 하는 결과 이름)를 적는다 — 검사기가 막음.
  - 예 (글 1212): 본문 표 합계 34,428,900원 = 3,442.89만원 → 반올림 약 3,443만원
  - 예 (글 989): '대체공휴일까지 반영해 바로 세어 줘요' — 2026~2027년 밖 날짜는 공휴일이 반영 안 됨

## 지역·일부 기관 기준을 전국 기준처럼 (7곳)
- 왜 틀렸나: 한 지역·한 기관 자료만 찾고 전국 공통인지 확인하지 않은 채 일반 문장으로 씀 (#482·#493).
- 쓸 때: 한 지역·한 기관 자료면 그 이름을 문장(제목·요약 포함)에 밝힌다.
  - 예 (글 493): 등록증 구비서류 안내는 강동구 페이지에서만 확인 — 지자체 일반처럼 쓰지 않음
  - 예 (글 493): 검사 순서는 공단 검사소 안내 기준, '서류보다 부적합 많다' 근거 없음

## 확인 못 한 것을 '없다'고 단정 (5곳)
- 왜 틀렸나: 검색으로 못 찾은 것을 '없다'로 씀 (#219·#448).
- 쓸 때: 못 찾은 것을 '없다·0개'로 쓰지 않는다 (공식 목록으로 확인했을 때만).
  - 예 (글 690): '법에 그런 이름이 없다'는 법령 전체를 확인해야 하는 부정 단정 — 금감원 금융상품한눈에는 '입출금자유예금'으로만 설명
  - 예 (글 448): 제목의 '국가공인 0개' 공식 확인 안 됨
